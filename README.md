🧮 Marks & Attendance Calculator
📖 Description

This is a simple and interactive Marks and Attendance Calculator built using HTML, CSS, and JavaScript.
It allows users to easily calculate their total marks, percentage, and attendance percentage. The app features a clean user interface and real-time calculations, making it a helpful tool for students and teachers alike.

🚀 Features

✅ Calculate total and average marks

📊 Calculate attendance percentage

🔄 Real-time updates on input change

💡 Simple, clean, and responsive design

💻 Built with pure HTML, CSS, and JavaScript — no frameworks needed

🧠 How It Works

Enter the marks for each subject.

Enter the total number of classes and attended classes.

Click the Calculate button to view your total, percentage, and attendance details instantly.
